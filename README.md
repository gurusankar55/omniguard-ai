# 🛡️ OmniGuard AI | Advanced Autonomous Web3 Security Suite

> Built for the **Openserv Open Track Competition**, **OmniGuard AI** is an advanced autonomous multi-agent Web3 security mesh designed to protect users against real-time exploits, malicious phishing domains, and smart contract drainers on **Base Sepolia**.

* **Access the Live App:** [https://omniguard-ai-chi.vercel.app/](https://omniguard-ai-chi.vercel.app/)

## 🔥 Core Security Modules

1. **🛡️ Phishing URL Hunter:**
   * Scans DApps and website inputs against known malicious signatures and heuristic threat patterns to instantly flag token-drainer websites.

2. **🚨 Emergency Circuit Breaker (Rug-Pull Defense):**
   * Real-time emergency protocol that allows users to instantly lock their vault and trigger an immediate fund evacuation to a pre-designated secure wallet address via Web3 wallet signatures.

3. **🧪 AI Transaction Simulator & State Auditor:**
   * Simulates smart contract executions and token approvals off-chain before signing, preventing unauthorized balance drainage and allowance exploits.

4. **💸 Secure Intent Transaction Sender:**
   * Executes verified native ETH transfers on **Base Sepolia** with integrated AI intent evaluation and automated gas safety checks.

5. **📡 Live Global Threat Intelligence Feed:**
   * Real-time telemetry tracking newly intercepted phishing nodes, high gas anomalies, and global Web3 threat actors.

## 🛠️ Tech Stack & Architecture
* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (High-performance reactive UI).
* **Web3 Integration:** Native Ethereum Provider (MetaMask / Rabby), Viem, EIP-1193 standard wallet interactions.
* **Network:** Base Sepolia Testnet (`Chain ID: 0x14a34`).
* **Hosting & Deployment:** Vercel Edge Network.

## 📦 Local Setup & Installation

To run this project locally on your machine:

```bash
# Clone the repository
git clone [https://github.com/gurusankar55/omniguard-ai.git](https://github.com/gurusankar55/omniguard-ai.git)

# Navigate to the project directory
cd omniguard-ai

# Install dependencies
npm install

# Start the local development server
npm start
